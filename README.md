# Exercices JavaScript

Mes exercices de JavaScript : événements, manipulation du DOM et formulaires.

## Organisation

```text
Exercices-JS-2/     Série 2 — exercices 1 à 6
Exercices-JS-3/     Série 3 — exercices 1 à 4
README.md          Présentation et navigation
```

Chaque exercice conserve son fichier `index.html` et, lorsqu'ils existent, son `script.js`, sa feuille de style et ses images.

## Ouvrir un exercice

Dans VS Code, ouvrir le dossier du dépôt, puis le fichier `index.html` de l'exercice dans un navigateur, directement ou avec Live Server. Aucune installation de dépendances n'est nécessaire.

## Enregistrer son travail avec Git

Enregistrer les fichiers dans VS Code, puis lancer depuis la racine du dépôt :

```powershell
git status
git add .
git commit -m "Avancer les exercices JavaScript"
git push origin main
```

Un seul dépôt Git gère les deux séries : ne pas lancer `git init` dans les sous-dossiers d'exercices.
